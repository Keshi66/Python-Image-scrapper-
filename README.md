# Python-Image-scrapper-
---> Installation & Usage

1.Clone the Repository

git clone https://github.com/your-username/image-scraper.git
cd image-scraper


2.Install Dependencies

pip install -r requirements.txt


3.Run the Scraper

python scraper.py --query "cats" --limit 200


(Downloads 200 cat images into the output/ folder)
